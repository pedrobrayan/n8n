Esse é o repositório com um agente de IA criado por mim no n8n, utilizando a LLM GPT-5 mini. O agente foi desenvolvido para auxiliar o usuário no sistema Property Management, também desenvolvido por mim. Ele é capaz de criar eventos na agenda do usuário, como períodos de reforma, lembretes de cobrança de aluguel e vencimento de contas, redigir e-mails de cobrança de aluguel ou de contas, e responder a perguntas sobre imóveis e inquilinos sem a necessidade de abrir o sistema, realizando consultas diretamente no banco de dados.
